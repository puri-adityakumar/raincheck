# Blog assets

The DEV write-up for the Hacktoberfest Open-Source AI Challenge, Week 3: Slow and Steady.

- [`raincheck-slow-and-steady.md`](raincheck-slow-and-steady.md): the post, using the challenge submission template. Images point at this repository's raw GitHub URLs.
- `assets/banner.png`: cover image (1000×420 at 2×).
- `assets/diagrams/`: architecture, ticket lifecycle, and "lazy payoff" diagrams.
- `assets/screenshots/`: real screenshots of a local production build with AI drafting off and live Open-Meteo weather. The share-link token is masked.
- `assets/video/raincheck-demo.mp4`: a 55-second narrated walkthrough (1280×720, H.264/AAC). The narration is Microsoft Edge neural text-to-speech (en-US-AndrewMultilingualNeural, generated with the open-source `edge-tts` tool). The script is in [`assets/video/narration.txt`](assets/video/narration.txt).
